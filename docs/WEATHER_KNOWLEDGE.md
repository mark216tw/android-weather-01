# 天氣知識教學

本文件說明「簡單天氣」畫面中的氣象指標，以及閱讀數值時應注意的限制。App 使用 Open-Meteo 模型預報，適合日常行程參考，不應取代中央氣象署、地方政府或其他官方單位發布的警報。

## 溫度與體感溫度

App 顯示距地面約 2 公尺的氣溫，單位為攝氏（°C）。體感溫度還會考量濕度、風與太陽輻射；炎熱潮濕時通常高於氣溫，寒冷且風大時則可能低於氣溫。

## 相對濕度

相對濕度是目前水氣相對於同溫度下空氣可容納最大水氣量的比例。

| 相對濕度 | 一般感受 |
| --- | --- |
| 低於 40% | 較乾燥 |
| 40–60% | 多數人感覺較舒適 |
| 高於 60% | 較潮濕，炎熱時體感容易升高 |
| 高於 80% | 非常潮濕，常見於雨天、霧或清晨 |

高濕度不代表一定會下雨，仍需搭配降雨機率、雲量與氣壓判讀。

## 降雨機率與降雨量

- 降雨機率代表指定地點與時段發生可測降水的可能性，不是降雨時間占比。
- 降雨量單位為毫米（mm）；`1 mm` 約等於每平方公尺累積 1 公升的水。
- 「當下降雨量」是目前模型時間間隔內的累積值，每日預報則是當天總降水量。

## 風速、風向與蒲福風級

App 顯示距地面約 10 公尺的風速，單位為公里／小時。風向表示風吹來的方向，例如北風是由北向南吹。蒲福風級將風速轉成級數與名稱，但陣風可能高於平均風速，戶外活動仍應留意官方強風特報。

## 海平面氣壓

App 使用 `pressure_msl`，即校正至海平面的氣壓，單位為百帕（hPa）。標準海平面氣壓約為 `1013.25 hPa`。

### App 簡化分級

| 海平面氣壓 | 類型 | 常見天氣特徵 |
| --- | --- | --- |
| 低於 980 hPa | 強烈低壓 | 可能伴隨強風、豪雨與緊密環流 |
| 980–1010.9 hPa | 低氣壓 | 多雲、不穩定、較容易降雨 |
| 1011–1019.9 hPa | 接近平均 | 接近標準海平面氣壓 |
| 1020–1039.9 hPa | 高氣壓 | 通常較穩定、晴朗、少雲 |
| 1040 hPa 以上 | 強高氣壓 | 通常穩定且較乾燥 |

這些區間是方便閱讀的簡化分級，不是災害判定標準。單一地點低於 `980 hPa` 不能證明當地有颱風：颱風認定還需環流、持續風速、衛星與雷達資料，而且公布的中心氣壓是風暴中心附近數值。氣壓快速下降通常比單一數值更值得注意，但本 App 目前未提供氣壓趨勢圖。

## 能見度

能見度是大氣中可辨識物體的最遠距離。Open-Meteo 回傳公尺，App 轉換成公里。

| 能見度 | App 分級 | 一般意義 |
| --- | --- | --- |
| 10 km 以上 | 良好 | 視野清晰 |
| 5–低於 10 km | 普通 | 遠景略受影響 |
| 1–低於 5 km | 不佳 | 霧、雨或污染可能影響視線 |
| 低於 1 km | 很差 | 視線明顯受限，行車需格外留意 |

霧、降雨、沙塵、煙霧與污染都會降低能見度。模型值不等同道路或機場現地觀測，駕駛時應以實際路況與官方資訊為準。

## 雲量

雲量表示天空被雲覆蓋的比例。

| 雲量 | App 描述 |
| --- | --- |
| 0–20% | 晴朗 |
| 21–40% | 大致晴朗 |
| 41–60% | 局部多雲 |
| 61–80% | 多雲 |
| 81–100% | 陰天 |

雲量高不一定會下雨；薄高雲可能覆蓋天空但不降雨，積雨雲則可能在較小範圍帶來強降雨。

## 紫外線指數

| UV 指數 | App 分級 | 建議 |
| --- | --- | --- |
| 低於 3 | 低量級 | 一般戶外活動仍可適度防曬 |
| 3–低於 6 | 中量級 | 使用防曬、帽子或遮蔽物 |
| 6–低於 8 | 高量級 | 減少正午曝曬並加強防護 |
| 8–低於 11 | 過量級 | 儘量避免長時間曝曬 |
| 11 以上 | 危險級 | 採取完整防曬措施 |

薄雲或雲邊反射下，UV 仍可能維持高值。

## 日出、日落與日照時數

- 日出與日落依查詢地點時區顯示。
- 日照時數是一天中直射日照達到氣象門檻的預估累積時間。
- 日照時數通常少於日出至日落總時長，因為雲層會遮蔽陽光。
- App 以當地日出、日落切換淺色與深色主題。

## 月相

月相約每 29.5 天循環。App 顯示新月、眉月、上弦月、盈凸月、滿月、虧凸月、下弦月或殘月。月相不代表月亮一定可見，仍受月出月落、雲量、能見度與光害影響。

## US AQI 與 PM2.5

US AQI 數值越高代表健康風險越高：

| US AQI | 分級 |
| --- | --- |
| 0–50 | 良好 |
| 51–100 | 普通 |
| 101–150 | 對敏感族群不健康 |
| 151–200 | 對所有族群不健康 |
| 201–300 | 非常不健康 |
| 301–500 | 危害 |

PM2.5 是直徑不超過 2.5 微米的細懸浮微粒，單位為 `μg/m³`。App 使用 CAMS 模型資料，空間解析度與地方測站不同；健康決策請優先參考所在地官方監測站。

## 海拔高度

海拔是 Open-Meteo 地形網格用於天氣模型降尺度的高度，不是手機 GPS 即時測得的高度。山區或地形快速變化處可能與實際位置有差異。

## 綜合判讀範例

- 低氣壓、雲量高、濕度高、降雨機率上升：較可能出現陰雨天氣。
- 高氣壓、雲量低、能見度良好：通常較穩定晴朗。
- 高濕度、低能見度、風速弱：清晨或夜間可能有霧。
- PM2.5 偏高、能見度下降但濕度不高：可能受到污染或煙霧影響。
- 氣壓下降、風速增加、降雨機率升高：天氣可能轉壞，應查看官方警報。

## 資料限制與安全提醒

- App 顯示模型格點資料，不是使用者所在地的即時測站讀數。
- 山區、海岸、都市熱島及局部對流可能造成明顯差異。
- 預報時間越遠，不確定性通常越高。
- 颱風、豪雨、雷擊、強風、低能見度及空氣污染事件，請以官方警報與現地狀況為準。
